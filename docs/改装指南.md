# 改装指南

团子能改的地方分好几层，从完全不写代码，到整只自己画：

| 想做的事 | 怎么做 |
|---|---|
| 要一只新团子，不想动手 | 右键 →「AI 捏团子」，说一句话 |
| 自己调颜色、加小配件 | 写一个「配方」文件，放进团子文件夹 |
| 整只自己画、换扭蛋的样子 | 写「完整画法」和扭蛋样式 |
| 把自己做的分享给别人 | 把那个 `.json` 文件发过去 |
| 加功能（提醒、联动别的软件） | 写插件，见 [README](../README.md#插件) |

## 团子文件夹

`%APPDATA%\dango-pet\dangos\`。在图鉴最下面点「团子文件夹」可以直接打开。

- 往里放 `.json` 文件，再打开一次图鉴就生效，不用重启。
- 一个文件算一「包」。图鉴里每一包有个开关，关掉就不会再抽到它；自带的 17 只也是一包，同样能关。
- 别人给你的包，放进这个文件夹就能用；不想要了，在图鉴里点「删掉」。
- 写错了不会出事：有问题的那一只会被跳过，原因记在 `%APPDATA%\dango-pet\pet.log` 里。

## 一、AI 捏团子

1. 右键 →「AI 捏团子」。第一次要填接口：用 Claude 的话填密钥就行；用别家的，选「其它（OpenAI 兼容）」，填接口地址、模型名和密钥。本机跑的模型（比如 Ollama）填 `http://localhost:端口/v1`，不用密钥。
2. 写一句描述，比如「戴墨镜的柠檬团子」，点「捏一只」。
3. 满意点「收下」，不满意点「重捏」。

收下的团子存成团子文件夹里的 `ai-xxxx.json`，就是下面说的配方，可以接着手改。

关于联网和花费：只有点「捏一只」的那一下才联网，发出去的只有你写的那句话和一段固定的格式说明；密钥加密存在你电脑上。费用算在你自己的接口账号上，一次大约几千个 token。

## 二、配方

配方是最省事的写法：身体形状不用管，只说颜色、耳朵、花纹和小配件。

```json
{
  "name": "柠檬团子",
  "say": "酸得眯眼，提神",
  "lines": ["来一口？", "维 C 拉满"],
  "colors": { "outline": "#7a6410", "body": "#ffe14d", "belly": "#fff6b0", "accent": "#6fbf3f", "accent2": "#ffffff", "eye": "#2b1d10" },
  "topper": ["..aa..", ".aaaa.", "..n..."],
  "front": [[6, 14, "#26262e", 5, 3], [17, 14, "#26262e", 5, 3], [11, 15, "#26262e", 6, 1]]
}
```

| 字段 | 意思 |
|---|---|
| `name` | 名字（必填） |
| `say` | 图鉴里的一句介绍 |
| `lines` | 它会说的话，最多 4 句 |
| `rarity` | `N` 普通 / `R` 稀有 / `SSR` 隐藏：写了就按这个稀有度进抽奖池；不写算「自制」，四次里大约有一次抽到自制的 |
| `colors` | `outline` 描边和 `body` 身体必填；`belly` 肚皮、`accent` 主点缀色、`accent2` 副点缀色、`eye` 眼睛可选。都写成 `#rrggbb` |
| `belly` | 写 `false` 就不要浅色肚皮 |
| `ears` | `cat` 猫耳 / `bunny` 兔耳 / `bear` 圆耳 / `horn` 小角，不写就没有 |
| `tail` | `cat` / `devil`，不写就没有 |
| `pattern` | 身体花纹：`stripes` 斜条 / `dots` 波点 / `bands` 横条 / `checker` 格子，用 `accent2` 的颜色 |
| `topper` | 头顶的小东西：一行一个字符串，从上到下，最多 8 行。会自动居中，最后一行贴着头顶 |
| `marks` | 画在身体上、五官下面的小色块：`[x, y, 颜色, 宽, 高]` |
| `front` | 画在五官上面的小色块（眼镜、口罩）：格式同上 |

`topper` 里每个字符代表一种颜色：`.` 空白，`o` 描边色，`b` 身体色，`a` accent，`w` accent2，`k` 黑，`r` 红，`y` 黄，`g` 绿，`p` 粉，`u` 蓝，`n` 棕。

**坐标**：画布 28×24，`x` 从左到右 0~27，`y` 从上到下 0~23。

| 部位 | 位置 |
|---|---|
| 身体 | x 3~24，y 8~23 |
| 眼睛 | 左 x 7~9，右 x 18~20，y 14~16 |
| 嘴 | (13~14, 17) |
| 腮红 | (5~6, 17) 和 (21~22, 17) |
| 头顶上方的空地 | y 0~7 |

## 三、团子包

一个文件里放好几只，还可以带一个扭蛋样式：

```json
{
  "name": "水果包",
  "capsule": { "name": "西瓜", "pal": { "c": "#58b368", "k": "#3d9150", "t": "#8fd39a" } },
  "dangos": [
    { "name": "青柠团子", "colors": { "outline": "#4f6a1c", "body": "#b8e06a" }, "pattern": "dots" },
    { "name": "草莓团子", "rarity": "R", "colors": { "outline": "#7a2a3a", "body": "#ff8fa3", "accent2": "#ffe6ea" }, "ears": "bunny" }
  ]
}
```

## 四、扭蛋样式

写在包的 `capsule` 里。装好后在图鉴底下的「扭蛋」一栏切换。

| 字段 | 意思 |
|---|---|
| `name` | 样式名 |
| `pal` | 换掉哪些颜色：`c` 底壳、`k` 底壳暗部、`t` 底壳亮部、`s` 接缝、`o` 描边、`g` 玻璃、`h` 高光。玻璃可以写 `#rrggbbaa`，最后两位是透明度 |
| `rows` | 想整个重画就写这个：12 行、每行 12 个字符，字符是 `pal` 里的字母，`.` 是空白。第 0~5 行是能掀开的上半 |
| `glass` | 写 `false` 表示上半不透明，看不见里面的团子 |

## 五、完整画法

想连身体形状都自己画，就不写 `colors`，改写 `pal` 和 `rows`：

```json
{
  "name": "方块团子",
  "pal": { "o": "#333344", "b": "#88aaff", "w": "#ffffff" },
  "rows": {
    "10": "......oooooooooooooooo......",
    "11": "......obbbbbbbbbbbbbbo......"
  },
  "eyes": { "x": [9, 16], "y": 14 },
  "shade": false
}
```

- `pal`：字母 → 颜色，必须有 `o`（描边）和 `b`（身体）。
- `rows`：行号 → 这一行的 28 个字符，写了哪一行就整行替换。`half` 同理，但只写左半 14 个字符，右半自动镜像。
- 还能用的字段：`over`（贴一小块 `[x, y, [行…]]`）、`tail`（尾巴，单独会摇）、`marks`、`front`、`eyes`、`mouth`、`blush`、`e`（眼睛颜色）、`belly`、`shade`、`ear`（行号小于它的像素算耳朵，会抖）、`pattern`。

自带的 17 只都是这种写法，在 [`src/sprites.js`](../src/sprites.js) 的 `FORMS` 里，可以照着抄。

## 改源码

拿到源码以后随便改：形象在 `src/sprites.js`，台词在 `src/lines.js`，动画在 `src/pet.html`，逻辑在 `src/core.js`，AI 那段说明文字在 `src/ai.js` 开头。改完 `npm start` 看效果，`npm test` 跑自测，`npm run dist` 打安装包。
